plan/80 i18n 抽出フォローアップ

既に入っている i18n 基盤を変えず、未抽出の sandbox 関連 UI 文字列を英語カタログへ移します。 表示される英語文言は変更しません。

成功条件

  • Wave 1c〜1f の対象文字列が t('sandbox.*') に置き換わっている。
  • 抽出済みファイルが I18N_ENFORCED_FILES に追加され、回帰 lint が効く。
  • catalog completeness と対象コンポーネントテストが通る。
  • plan/80.md と i18n ドキュメントが実装状態と一致する。

作業順序

1. baseline
先に npm run size の現状を記録。
2. intro
sandbox.intro.* を抽出。
3. edits/annotations
sandbox.edits.* と sandbox.annotations.* を抽出。
4. recording/snapshots
sandbox.recording.* と sandbox.snapshots.* を抽出。
5. assessment
sandbox.assessment.* を抽出。
6. validation
targeted tests から full gate まで実行。
注意点
  • annotation 本文、recording title、snapshot name などユーザー入力は i18n 対象外。
  • 文言改善はしない。既存の英語文字列をそのままカタログ化する。
  • 新しい i18n ライブラリや ICU 構文は導入しない。
