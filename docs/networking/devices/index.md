# Networking Devices

> **Status**: Implemented

Netlab models common teaching devices as layer-aware topology nodes. Device docs
explain how each node type participates in visualization and packet forwarding.

## Device Specs

- [Hub](hub.md) - L1 broadcast device used to show shared-medium behavior
- [Router](router.md) - L3 forwarding device with route tables and protocol config
- [Switch](switch.md) - L2 forwarding device with MAC learning and VLAN behavior
